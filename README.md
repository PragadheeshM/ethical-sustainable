## 🚀 Getting Started

1. **Open the Website**
   - Simply open `pages/index.html` in your browser
   - Or use a local server for best experience

2. **Navigate Pages**
   - All pages are interconnected via the navbar
   - Use the navigation menu to explore

3. **Customize**
   - Edit colors in `assets/css/style.css`
   - Modify content in individual HTML files
   - Update JavaScript in `assets/js/main.js`

## 🎨 Customization

### Colors
Edit the color variables in `assets/css/style.css`:
```css
:root {
  --primary-green: #10b981;
  --dark-green: #059669;
  --accent-teal: #14b8a6;
}
```

### Dark Mode
Toggle is built-in and saves preference to localStorage.

### RTL Support
Click the globe icon in the navbar to toggle RTL mode.
